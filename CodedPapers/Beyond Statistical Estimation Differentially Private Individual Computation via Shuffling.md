notes: The paper provides a novel protocol for Differenitial Privacy. The protocol enables users to perform more valuable computations with private data while ensuring privacy by leveraging the user to locally add a one time public key to the data before being sent as an encrypted message to the shuffler (of the Shuffler DP model), called the Private Individual Computation paradigm. The paper also includes a local optimal randomizer called Minkowski Response. The ethics section assesses the benefits of the paper, and address that there are no ethical concerns as only public datasets were used for experiments, but otherwise is pretty minimal. The section 4.1 Motivating Application addresses 3 computation tasks, and how users would be motivated to use this protocol by explaining usage or incentives - which can be treated as a form of Usability Analysis.
